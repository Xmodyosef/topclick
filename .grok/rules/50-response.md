# Short Response Rules

- Reply in Arabic by default.
- Use 3–5 numbered points maximum unless the owner asks for detail.
- Keep each point to one short sentence.
- Start with status and result, then list only essential files, checks, and links.
- Do not repeat the same explanation or add comparisons unless requested.
- Always include the PR, commit, Actions, report, or IPA link when that artifact exists.
- If work is incomplete, state the blocker in one sentence.
