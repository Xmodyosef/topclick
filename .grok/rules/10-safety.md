# Safety and Evidence Rules

- Read the root `AGENTS.md` and `SKILLS.md` before changing files.
- Run `grok inspect` before the first implementation step when Grok Build is available.
- Never claim a fix, passing build, or completed review without fresh command output.
- Separate `verified by CI` from `verified on a physical iPhone`.
- Do not run an unfamiliar script before reading it.
- Do not delete releases, tags, branches, artifacts, or more than five files without explicit owner approval.
- Never expose secrets in logs, reports, commits, or PR comments.
- If evidence is unavailable, say exactly what remains unverified.
