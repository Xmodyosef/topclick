# نقرة — PersonalKeyboard

لوحة مفاتيح iOS عربية/إنجليزية.

## الحالة
- الإصدار: **0.2.8** (build 28)
- الحد الأدنى: iOS 17
- التوقيع: IPA غير موقّع (ESign / Feather)

## الميزات
- تبديل العربية/الإنجليزية (مسافتان)
- ثيمات متعددة + ثيم مخصص
- أصوات نقرة واهتزاز
- ترجمة (iOS 18+)
- إيموجي + Clipboard
- أيقونة صباح/مساء تلقائية (6ص–6م)

## الهوية (لا تُغيَّر)
- PRODUCT_NAME: PersonalKeyboard
- Bundle: app.personal.PersonalKeyboard
- Extension: app.personal.PersonalKeyboard.KeyboardExtension
- App Group: group.app.personal.PersonalKeyboard
- Notification: app.personal.PersonalKeyboard.prefs
- DisplayName: نقرة

## البناء
GitHub Actions → IPA غير موقّع → ESign

لا ترفع شهادات أو ملفات p12.


## مصادر
- الثيمات مستوحاة من [KeyboardKit](https://github.com/KeyboardKit/KeyboardKit) (MIT) — ليست نسخاً من الكود
- الأصوات مستوحاة من [Mechvibes](https://github.com/hainguyents13/mechvibes) (MIT)
- الأيقونات من SF Symbols
- ثيمات [Catppuccin](https://github.com/catppuccin/catppuccin) (MIT)
- ثيم [Dracula](https://github.com/dracula/dracula-theme) (MIT)
