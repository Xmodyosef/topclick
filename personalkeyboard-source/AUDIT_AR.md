# فحص شامل — نقرة (بعد التقسيم)

تاريخ: 2026-10-23

## أعطال أُصلحت في هذه الجولة
1. `showNumberRow` / `numberRow` كانت مستخدمة وغير معرّفة → فشل compile محتمل.
2. `hold_map` في JSON كان فارغًا → الضغط المطوّل على الحروف العربية معطل.
3. `validate_naqra.py` كان يفحص النسخة القديمة الموحّدة + `synchronize` → كان سيكسر CI بعد التقسيم.
4. مفتاح `sounds` يُقرأ في الامتداد بلا واجهة في الإعدادات.
5. كود ميت: `knownWord`، `loadPreparedTheme`.

## ما يعمل (مفترضًا بعد بناء IPA)
- تخطيط عربي/إنجليزي + Shift + رموز + إيموجي من JSON
- اقتراحات عربية من lexicon
- تصحيح إنجليزي عبر UITextChecker + تصحيحات عربية ثابتة
- ثيمات App Group + Darwin notify
- نسخ/لصق/ترجمة (مع Full Access و iOS 18 للترجمة)
- معاينة + إعدادات + أيقونات صباح/مساء

## ما يعتمد على Full Access / البيئة
- الحافظة وتاريخها
- الترجمة
- App Group بين التطبيق واللوحة (مهم جدًا عند التوقيع بـ ESign/Feather)

## ملاحظات ESign / Feather
- ابنِ unsigned من GitHub Actions ثم وقّع بالشهادة السنوية.
- يجب أن يشمل التوقيع **App Group** نفسه: `group.app.personal.PersonalKeyboard` للتطبيق والامتداد.
- فعّل اللوحة يدويًا: إعدادات → عام → لوحة المفاتيح → لوحات المفاتيح → نقرة → السماح بالوصول الكامل.
