Naqra iOS source tree
=====================

personalkeyboard-source/
├── App/
│   ├── Sources/
│   │   ├── AppShell/       # App entry, root view, icon switching
│   │   ├── Settings/       # Settings and translation preparation
│   │   └── Themes/         # Theme models, pack stores, theme UI
│   ├── Resources/
│   │   └── Assets.xcassets/
│   └── Config/             # Info.plist and app entitlements
├── KeyboardExtension/
│   ├── Sources/
│   │   ├── Lifecycle/     # KeyboardViewController lifecycle and core state
│   │   ├── Input/         # Text input, long-press, language and data loading
│   │   ├── UI/            # Keyboard rows, keys, toolbar and palette
│   │   └── Features/      # Emoji, clipboard, sound, themes and translation
│   ├── Resources/         # keyboard_layouts.json and emoji_catalog.json
│   └── Config/            # Extension Info.plist and entitlements
├── Shared/
│   └── Models/            # SharedKeyboardData used by both targets
├── Tests/NaqraTests/      # XCTest regression tests
├── scripts/               # Version validation and release helpers
└── project.yml            # XcodeGen source/resource/target declarations

Placement rules
---------------
- Keep app-only UI and stores inside App/Sources.
- Keep keyboard-extension runtime code inside KeyboardExtension/Sources.
- Keep JSON extension resources outside Sources and register them explicitly in project.yml.
- Keep Info.plist and entitlements in each target's Config directory.
- Put code compiled by both targets in Shared, then list it for both targets.
- Keep Tests and scripts at the project root; update CI and validators whenever paths move.
- Folder moves must not change Swift behavior, bundle identifiers, App Group, or versions.
