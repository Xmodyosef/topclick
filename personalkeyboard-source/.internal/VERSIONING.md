# Versioning

- Marketing (CFBundleShortVersionString / MARKETING_VERSION): **0.2.4** then **0.2.5**, **0.2.6**, …
- Build (CFBundleVersion / CURRENT_PROJECT_VERSION): integer, +1 each release (now **20**)
- Do not go back to bare `0.2` — keep three-part `0.2.x` sequence.
- Tag releases as `v0.2.x` matching marketing version (not `v1.0.0`).
